# PLANIFICATION — Portfolio

## Mes 4 choix technologiques pour le portfolio

### 1. Gestion des données

#### Choix : JSON local

Les informations de mes projets seront enregistrées dans un fichier JSON
local dans le dépôt GitHub.

Le fichier contiendra notamment :

- le titre du projet
- la catégorie
- la description
- les images
- les technologies utilisées
- les liens associés au projet

### 2. Animations

#### Choix : CSS + Anime.js

CSS sera utilisé pour les animations simples :

- hover
- changements d'opacité
- transitions
- transformations légères

Anime.js sera utilisé pour les animations plus créatives.

### 3. Structure de Nav.

#### Choix : One-pager + fenêtres modales

Le portfolio sera principalement constitué d'une seule page comprenant :

1. Hero
2. À propos de moi
3. Intérêts
4. Skills & Expertise
5. Projets
6. Contact
7. Footer

Le menu permettra de naviguer directement vers les différentes sections.

Lorsqu'un utilisateur sélectionne un projet, une fenêtre modale permettra
d'afficher davantage d'informations sans quitter la page principale.

### 4. Hébergement

#### Choix : GitHub Pages

Le portfolio sera hébergé avec GitHub Pages.
